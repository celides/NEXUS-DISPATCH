# NEXUS DISPATCH

> Multi-Platform Content Deployment Studio

Herramienta web que permite preparar una pieza de contenido (video, copy, hashtags) una sola vez y desplegarla simultáneamente en múltiples plataformas sociales. Diseñada para creadores de contenido, marcas y proyectos que publican en varias redes sin depender de APIs de pago ni herramientas de suscripción mensual.

---

## 🎯 El problema

Publicar el mismo video en TikTok, YouTube Shorts, Facebook Reels, Instagram Reels, Threads y Kwai es tedioso: hay que subir el archivo manualmente en cada plataforma, copiar y pegar el título, la descripción y los hashtags una y otra vez. Las herramientas que automatizan esto cobran suscripciones mensuales (entre $6 y $30 USD/mes) y las APIs oficiales tienen barreras de auditoría que bloquean a desarrolladores independientes.

## 💡 La solución

**NEXUS DISPATCH** centraliza la preparación del contenido en una sola interfaz y, con un clic, abre cada plataforma en una pestaña nueva con el texto ya copiado al portapapeles. El usuario solo pega el texto y selecciona el video desde su disco. Es un enfoque **manual-asistido**: rápido, gratuito, legal y sin riesgo de bloqueo por bots.

## ✨ Características

- **Interfaz futurista** inspirada en paneles de control tipo ciencia ficción.
- **Drag & drop** para el archivo de video (MP4, MOV, WEBM hasta 100MB).
- **Contador de caracteres** en tiempo real para título y descripción.
- **Hashtags rápidos** con un clic para insertar etiquetas comunes.
- **Selección múltiple de plataformas**: TikTok, YouTube, Facebook, Instagram, Threads y Kwai.
- **Copia automática al portapapeles** del copy completo formateado.
- **Consola de despliegue** con feedback paso a paso de cada acción.
- **Sin backend, sin base de datos, sin cookies**: 100% frontend, funciona offline.
